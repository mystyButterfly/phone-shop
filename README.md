# SPA E-Commerce Application

This project is an SPA e-commerce application built using React.js, Contex API for state management, products are taken from a array in js-file.

## Key Features

- **Context API for State Management**  
  Employs the **Context API** to manage global state efficiently, allowing easy sharing of data across components, such as cart items and customer details.

- **Dynamic Routing**  
  Utilizes **React Router** to manage seamless navigation through various pages.

- **Product Filtering and Sorting**  
  Users can filter products based on **price**, **type**, and **style**, as well as sort the product list using various criteria.

- **Search Functionality**  
  Features a **live search** capability that enables users to quickly find products by name.

- **Responsive Design**  
  The application is designed with responsiveness in mind, ensuring a smooth experience on both **desktop** and **mobile** devices.

- **Error Handling**  
  Implements basic error handling to manage empty states when no products match the selected filters, enhancing user experience.

- **User Authentication Simulation**  
  Although this is a frontend-only application, it simulates a complete e-commerce environment, including order confirmation and success messages.

## Technologies Used

- **React**: For building user interfaces with reusable components.
- **React Router**: For managing navigation and routing within the application.
- **Context API**: For efficient state management and data sharing across components.
